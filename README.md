# Quiz em C - Checkpoint 2 (CP2)

Projeto de Quiz interativo 

## Estrutura do Projeto
- `main.c`: Ponto de entrada do programa, contendo o menu interativo controlado por `while` e `switch`.
- `funcoes.c`: Implementação das funções de cadastro, listagem, gameplay e estatísticas.
- `funcoes.h`: Declaração das constantes e protótipos das funções.
- `README.md`: Documentação e instruções de uso.

## Como Compilar
Abra o terminal na pasta do projeto e execute:
```bash
gcc main.c funcoes.c -o programa
